# Fixed Code Examples Directory

This directory contains standalone, production-tested C code examples for classroom demonstrations and student exercises, organized cleanly by topic.

## Directory Structure

```text
code_examples/
├── pointers/
│   ├── swap.c       # Pointer dereferencing and pass-by-reference swap
│   └── debug_u.c    # Pointer arithmetic and memory layout demo
├── memory/
│   └── memory.c     # Stack vs Heap allocations, malloc/free lifecycle
├── stacks/
│   └── generic_stack.c # Void-pointer generic stack implementation in C
└── heap/
    └── test_heap.c  # Dynamic array resizing and memory reallocation
```
